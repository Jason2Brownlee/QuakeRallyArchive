* Play Information *

***This map only works with the Quake Rally patch from Impact Developments***

Type                    : Racing
Single Player           : for practice and time attack
Bot Markers             : No (Maybe later if the bot code is resolved)
Cooperative             : No
Deathmatch              : 8 "deathmatch" starts for multiplay race
Difficulty Settings     : No
New Sounds              : No
New Graphics            : qrally.wad from Impact Developments
New Music               : No
Demos Replaced          : None

Put Vulcan.bsp in Rally/Maps directory
Start QRally using the launcher
When the demo starts bring down the console and type map vulcan
(or you can add +map Vulcan to the extra settings to jump straight to this track)
