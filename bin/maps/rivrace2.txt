* Play Information *

***This map only works with the Quake Rally patch from Impact Developments***

Type                    : Racing
Single Player           : for practice and time attack
Bot Markers             : No (Maybe later if the bot code is resolved)
Cooperative             : No
Deathmatch              : 8 "deathmatch" starts (best as 2 to 6) for multiplay race
Difficulty Settings     : No
New Sounds              : No
New Graphics            : No
New Music               : No
Demos Replaced          : None

Put Rivrace2.bsp in Rally/Maps directory
Start QRally using the launcher
(you can add +map rivrace2 to the extra settings to jump straight to this track)
When the demo starts bring down the console and type map rivrace2
