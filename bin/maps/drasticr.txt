* How to use this map (like you don't know this) *

- Copy "drasticr.bsp"  to "id1\maps\drasticr.bsp" (create "maps" 
  if necessary).
- Run Quake with "-game rally" command line.
- Bring up the console 
- Type "map drasticr" (without the quotes) from the console.
